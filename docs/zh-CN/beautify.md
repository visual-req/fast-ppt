# 美化指南

这份文档专门讲如何给 PPT 增加高质量视觉素材，重点覆盖三类图片：

- 背景图
- 装饰图
- 说明图

同时也补充一套“通过类似 ChatGPT Image 2 的图像生成工具生成高清图”的实操方法。

如果你已经有一套结构正确、内容基本完整的 deck，但看起来还不够“像成品”，这页最适合继续往下做。

## 先判断你需要的是哪一种图

不要一上来就说“多加点图”。  
先判断图片在这一页里承担什么职责：

| 类型 | 作用 | 最常见位置 | 推荐格式 |
|------|------|------------|----------|
| 背景图 | 提供氛围、质感、视觉开场 | 封面、开场页、少量摘要页 | PNG / JPG / WebP |
| 装饰图 | 增强视觉层次，不承担主信息 | 介绍页、人物页、双栏配图页 | PNG / WebP |
| 说明图 | 承担主要表达内容 | 产品截图、场景图、流程图、架构图 | PNG / JPG / SVG |

一句话判断：

- 想增强“气氛”：
  用背景图
- 想增强“页面饱满感”：
  用装饰图
- 想让用户“看懂某件事”：
  用说明图

## 当前工程里哪些地方原生支持图片

这点很重要，文档必须和真实代码对齐。

当前稳定可用的图片入口主要有这些：

### 1. 背景图

当前明确支持 `background` 字段的 layout：

- `cover`
- `title_bullets`
- `centered`

典型字段：

```json
{
  "background": {
    "src": "work/assets/001/001-cover-hero.png",
    "size": "cover",
    "position": "center",
    "overlay": "rgba(15, 23, 42, 0.42)"
  }
}
```

### 2. 插图 / 装饰图 / 说明图

当前稳定支持图片块的方式：

- `two_column` 的 `left.image` / `right.image`
- `profile_intro` 的 `photo`
- 一些带图的说明型 layout

`two_column` 中常用写法：

```json
{
  "layout_type": "two_column",
  "title": "核心能力概览",
  "left": {
    "bullets": [
      "统一管理需求、评审、产出和回改",
      "支持结构化页面生成与预览导出"
    ]
  },
  "right": {
    "image": {
      "src": "work/assets/001/012-product-screen.png",
      "alt": "产品界面示意图",
      "caption": "系统主界面示意"
    }
  }
}
```

### 3. 大图说明

如果图片本身就是主要表达对象，优先用：

- `svg_full`

这类页面更适合：

- 架构图
- 关系图
- 总览图
- 路线图
- 流程图

如果本质上是“结构说明”，优先用 SVG，不要退回普通位图。

### 4. 一个容易误判的点

当前 `section_divider` 组件并不是原生通过 `background` 字段加载背景图的。  
如果你想让章节封面也换成真实背景图，有两种做法：

1. 先使用当前默认 `section_divider`
2. 或者扩展 viewer 组件，再支持 `background`

也就是说，封面背景图现在最稳的是 `cover`，不是所有“看起来像封面”的 layout 都已经支持背景字段。

## 一、如何增加高清背景图

### 适合加背景图的页面

优先考虑：

- `cover`
- 需要强视觉开场的摘要页
- 少量过渡页或品牌页

不建议大面积滥用背景图的页面：

- 表格页
- 图表页
- 信息密度很高的结构页
- 需要精读的说明页

因为背景太重，很容易影响可读性。

### 背景图的质量要求

建议至少满足：

- 比例：16:9
- 分辨率：至少 `1920x1080`
- 更推荐：`2560x1440` 或 `3840x2160`
- 不要自带文字
- 不要自带 logo、水印、边框
- 画面中要主动留出标题区

一个好背景图最重要的不是“炫”，而是：

- 有氛围
- 不抢标题
- 留白合理
- 导出后不糊

### 存放位置

建议按项目归档：

```text
work/assets/001/
work/assets/002/
work/assets/003/
```

推荐命名：

```text
001-cover-hero.png
001-cover-hero@2x.png
002-summary-bg.jpg
003-brand-bg.webp
```

### 添加步骤

#### 1. 准备高清图

把图放到：

```text
work/assets/项目编号/
```

例如：

```text
work/assets/001/001-cover-hero.png
```

#### 2. 修改页面 JSON

如果是 `cover`，可直接加：

```json
{
  "layout_type": "cover",
  "title": "fast_ppt 使用说明",
  "subtitle": "从结构生成到网页预览与 PPTX 导出",
  "background": {
    "src": "work/assets/001/001-cover-hero.png",
    "size": "cover",
    "position": "center",
    "overlay": "rgba(15, 23, 42, 0.46)"
  }
}
```

字段含义：

- `src`：真实图片路径
- `size`：通常用 `cover`
- `position`：常用 `center`
- `overlay`：加深遮罩，保证标题可读

#### 3. 在 viewer 中检查

重点看：

- 标题是否清晰
- 背景是否被裁切得太厉害
- 重要主体是否被标题挡住
- 图片是否发灰、发虚、偏脏

#### 4. 再做一次导出检查

背景图在 viewer 里能显示，不代表导出就一定理想。  
还要确认：

- PPTX 中是否正常出现
- 是否被压缩得明显发糊
- 是否出现拉伸、黑边、错位

### 背景图的实操建议

- 优先选择“有层次但不复杂”的画面
- 封面图不要让主体正好卡在标题中心区域
- 左上大标题页，建议背景主体偏右
- 居中标题页，建议背景主体不要占正中央最亮区域
- 宁可轻一点，也不要太花

## 二、如何增加装饰图

装饰图不是主表达，但能让页面明显更饱满。

### 适合装饰图的页面

- 人物介绍页
- 双栏说明页
- 功能简介页
- 场景说明页
- 方案摘要页

### 装饰图和背景图的区别

背景图：

- 铺在页面底层
- 更多承担氛围

装饰图：

- 通常在内容区里
- 体积更小
- 起辅助解释和视觉支撑作用

### 最稳的装饰图落点

#### 1. `two_column` 右侧图片

最通用，也最好控。

示例：

```json
{
  "layout_type": "two_column",
  "title": "协作流程概览",
  "left": {
    "bullets": [
      "结构先行，减少反复回改",
      "支持 viewer 预览与导出 PPTX",
      "可继续沉淀为标准 layout"
    ]
  },
  "right": {
    "image": {
      "src": "work/assets/001/021-flow-visual.png",
      "alt": "流程说明配图",
      "caption": "用于增强页面饱满度和节奏感"
    }
  }
}
```

#### 2. `profile_intro.photo`

适合：

- 讲师介绍
- 团队核心成员
- 顾问简介

示例：

```json
{
  "layout_type": "profile_intro",
  "title": "讲师介绍",
  "photo": {
    "src": "work/assets/001/030-lecturer-photo.png",
    "alt": "讲师照片",
    "caption": "十年企业数字化咨询经验"
  }
}
```

### 装饰图的质量要求

- 画面主体要明确
- 不要信息太杂
- 不要出现小字截图
- 不要拿低清网页截图硬放大
- 最好和页面主色调兼容

### 装饰图的推荐风格

常见可用风格：

- 柔和科技感
- 轻商务插画
- 真实产品场景图
- 模糊背景上的主体物
- 低信息密度的空间感场景

装饰图的关键不是“信息多”，而是“有节奏、不卡阅读”。

## 三、如何增加说明图

说明图和装饰图不一样，它承担的是主要理解任务。

### 什么时候应该用说明图

出现这些情况时，应优先补说明图：

- 产品功能很抽象
- 业务场景不易理解
- 页面全是文字，读者看不出对象长什么样
- 希望展示真实界面、真实流程、真实使用场景

### 说明图的三种常见来源

#### 1. 产品截图

适合：

- 展示真实系统界面
- 展示页面结构
- 展示工作台、表单、看板、报表

#### 2. 场景示意图

适合：

- 展示用户在什么环境下使用产品
- 展示业务流程落地场景

#### 3. 结构说明图

适合：

- 多模块关系
- 架构分层
- 路线图
- 流程图

这类如果可以，优先转为 SVG。

### 添加说明图的步骤

#### 1. 判断这是位图还是 SVG

如果是：

- 真实截图、实拍场景、渲染图：
  用 PNG / JPG / WebP
- 架构、关系、流程、结构：
  优先用 SVG

#### 2. 把文件放入 `work/assets/`

例如：

```text
work/assets/002/018-dashboard-screen.png
work/assets/002/019-scene-render.webp
work/assets/002/020-architecture-overview.svg
```

#### 3. 在页面 JSON 中引用

截图说明型页面示例：

```json
{
  "layout_type": "two_column",
  "title": "项目空间首页",
  "left": {
    "bullets": [
      "统一展示项目状态、任务进度和风险提醒",
      "支持跨角色查看同一套交付链路"
    ]
  },
  "right": {
    "image": {
      "src": "work/assets/002/018-dashboard-screen.png",
      "alt": "项目空间首页截图",
      "caption": "示例工程中的项目空间首页"
    }
  }
}
```

结构说明型页面示例：

```json
{
  "layout_type": "svg_full",
  "title": "总体架构",
  "svg": {
    "src": "work/assets/002/020-architecture-overview.svg",
    "alt": "总体架构图",
    "caption": "通过 SVG 承担主表达"
  }
}
```

### 说明图的选择原则

- 能用真实截图，就不要只放抽象插画
- 能用结构图讲清，就不要堆一堆 bullets
- 说明图要服务页面意图，不是为了“看起来有图”

## 四、如何通过类似 ChatGPT Image 2 的工具生成高清图

这里说的不是某一个固定产品按钮，而是一类能力：  
你可以向图像生成工具发送自然语言提示，让它生成高质量背景图、场景图、插画或产品概念图。

适用工具包括：

- ChatGPT 图像生成能力
- 其他支持高分辨率输出的文生图工具
- 具备二次修改、多轮迭代能力的 AI 绘图工具

## 五、生成高清图的推荐工作流

### 第 1 步：先定义图片角色

先明确你要的是：

- 背景图
- 装饰图
- 说明图

如果角色不明确，生成提示词很容易跑偏。

### 第 2 步：把页面需求翻成图片要求

建议至少说清这 6 件事：

1. 主题是什么
2. 用在什么页面
3. 想突出什么主体
4. 希望什么风格
5. 要不要留白给标题
6. 输出比例和清晰度要求

### 第 3 步：明确写出画幅和清晰度

建议在提示词中直接写：

- `16:9`
- `1920x1080 or higher`
- `4K`
- `high detail`
- `clean composition`

如果是封面背景图，建议再补：

- `no text`
- `no watermark`
- `leave space for title`

### 第 4 步：先拿 2-4 个版本，再挑方向细化

不要一开始就赌一张图。  
更稳的做法是先拿几个方向：

- 偏科技
- 偏商务
- 偏极简
- 偏场景化

然后再继续收敛。

### 第 5 步：下载后不要直接上

先检查：

- 清晰度够不够
- 构图有没有遮挡标题
- 有没有奇怪文字、伪 logo、伪界面
- 色调是否和 deck 主题冲突

## 六、适合直接复用的提示词模板

下面这些模板可以直接改。

### 1. 背景图提示词模板

```text
请生成一张 16:9 的高清 PPT 封面背景图，用于 AI 产品方案演示。整体风格为现代、专业、科技感、轻商务。画面要有明显层次和留白，主体偏右，左侧保留大标题区域。不要出现任何文字、logo、水印、边框，不要出现拥挤元素。分辨率至少 1920x1080，要求 high detail，clean composition，适合深色遮罩后叠加白色标题。
```

适合：

- `cover`
- 开场摘要页

### 2. 装饰图提示词模板

```text
请生成一张 16:9 高清插画，用于企业级软件产品介绍页右侧配图。画面主题为团队在数字化工作台前协作，风格现代、简洁、可信、轻科技感。主体清晰，背景不要过满，保留适度留白。不要出现任何文字、logo、水印。分辨率至少 1920x1080，high detail。
```

适合：

- `two_column` 配图位
- 产品简介页

### 3. 说明图提示词模板

```text
请生成一张 16:9 高清场景图，用于说明“AI 协助团队完成需求分析和 PPT 生成”的业务场景。画面包含大型显示屏、结构化内容卡片、团队协作动作，强调工作流和信息层次。整体风格专业、清晰、真实可用，不要出现任何文字、logo、水印。分辨率至少 1920x1080，high detail。
```

适合：

- 场景介绍
- 方案说明
- 演示页

### 4. 如果你想要更可控

可以在提示词中继续加入：

- 主色调：蓝、青、白、深灰
- 镜头角度：isometric / front view / top-down
- 画面密度：minimal / medium density
- 光线：soft light / studio lighting
- 风格：realistic / semi-realistic / clean illustration

## 七、让 AI 生成图更稳定的几个技巧

### 技巧 1：明确写“不要文字”

很多图像工具会偷偷生成伪英文、伪 logo。  
所以建议明确写：

- no text
- no logo
- no watermark

### 技巧 2：明确写“为 PPT 留白”

例如：

- leave space for title on the left
- keep the center clean
- avoid cluttered composition

### 技巧 3：明确写用途

比起只说“画一张科技图”，更好的写法是：

- 用于企业级软件方案封面
- 用于产品能力介绍页右侧配图
- 用于数字化转型汇报开场页

这样图像风格更稳。

### 技巧 4：先做背景图，再做说明图

因为背景图容错高、最容易先出效果。  
说明图要求更高，适合在 deck 结构稳定后再补。

## 八、图片落盘后的推荐检查清单

### 文件层

- 路径是否真实存在
- 文件名是否清晰
- 是否放进了对应项目目录

### 页面层

- 页面 JSON 是否已正确引用
- `alt` / `caption` 是否合理
- `overlay` 是否足够保证文字可读

### viewer 层

- 是否正常显示
- 是否有裁切
- 是否发虚
- 是否和文字抢视觉

### 导出层

- PPTX 中是否正常出现
- 是否拉伸
- 是否糊
- 是否位置偏移

## 九、一个推荐的美化顺序

如果你想把一套“能用但不好看”的 deck 提到更成品的状态，推荐按这个顺序：

1. 先给 `cover` 补高清背景图
2. 再给关键摘要页补少量装饰图
3. 再给重要说明页补截图或说明图
4. 对结构页补 SVG，而不是乱加位图
5. 最后统一检查 viewer 和导出效果

这样通常最省力，也最容易马上看出提升。
